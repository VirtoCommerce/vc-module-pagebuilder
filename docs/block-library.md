# Block Library

## Call To Action

Call To Action block allows displaying set of action buttons. 

![Call To Action block](media/blocks/call-to-action.png)

## Call To Action with Image

Call To Action with Image block allows displaying image and set of action buttons. 

![Call To Action with Image block](media/blocks/call-to-action-with-image.png)

## Features

Features block allows displaying list of features with Image, Text and Subtitle. 

![Image block](media/blocks/features.png)


## Image

Image block allows displaying image with alternative text. 

![Image block](media/blocks/image.png)


## Products

Products block allows displaying limited count of products with filter by keyword. 

![Products block](media/blocks/products.png)

## Text

Text block allows displaying text title with configurable header (H2..H4) and text. 

![Products block](media/blocks/text.png)

## Title

Title block allows displaying text title with subtitle. 

![Products block](media/blocks/title.png)

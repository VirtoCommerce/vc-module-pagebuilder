в файле настроек описываются следующие данные, которые будут использованы в приложении.

Большинство свойств могут быть как просто строкой, так и зарпосом или списком запросов, из которых потом получается (достаётся) необходимое значение.

* `templatesListUrl` – список шаблонов, либо `URL`, либо запрос к серверу, который вернёт список шаблонов. Работа с шаблонами описана в [документации](./schemas.md). TODO:

* `sectionsListUrl` – список секций/блоков, либо `URL`, либо запрос к серверу, который вернёт список секций. Формат ответа описан в [документации](./schemas.md). TODO:

* `templateUrl` – URL или запрос для получения выбранного шаблона.

* `saveTemplates` – URL или запрос для сохранения шаблона.
TODO: описать формат запроса для VirtoCommerce.

* `settingsDataRequest` – запрос для получения файла с настройками темы.

* `settingsSchemaRequest` – схема настроек темы. Используется для генерации формы редактирования темы и пресетов.

* `saveSettings` – URL или запрос для сохранения настроек темы. Формат запроса аналогичен `saveTemplates`.

* `uploadAssetsRequest` – это может быть запрос для сохранения assets, либо строка, которая будет использована как свойство в настройках для получения запроса.

* `fullPreviewUrl` – это строка (либо запрос/шаблон/скрипт, который используется для получения строки). Используется как урл для айфрейма предпросмотра. В него подставляется `path` и `type`. Например:
```js
{{settings.storefrontUrl}}{{settings.previewPath}}?ep={{location.origin}}
```
что преобразуется в:
```http
https://localhost:3000/designer-preview?ep=https://localhost:5001
```

* `skipTheme` – флаг, либо запрос из которого достаётся флаг, показывающий, можно ли работать с настройками темы.

* `skipTemplates` – флаг, либо запрос из которого достаётся флаг, показывающий, можно ли переключать шаблоны в данной теме.

* `assetsUrlTemplate` – шаблон запроса, по которому формируется URL для загрузки assets.

* `publishPages` и `publish` – объект, который содержит в себе настройки для публикации страницы. В нём есть следующие свойства:
  * `status` – URL для получения статуса публикации страницы.
  * `publish` – запрос для публикации страницы.
  * `unpublish` – запрос для отмены публикации страницы.

  если `publish` не задан, то функционал публикации страницы будет отключён. Кнопки в тулбаре не будут отображаться.

  `publishPages` используется для страниц в рамках подхода VirtoPages.

* `externalPreview` – объект со свойством `url`, в котором прописан шаблон формирования урла для предпросмотра страницы в "боевой" среде. При нажатии кнопки предпросмотра в тулбаре, будет открываться новое окно с этим урлом.

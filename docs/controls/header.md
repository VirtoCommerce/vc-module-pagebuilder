# Header Control Descriptor

| Property  | Description |
| - | - |
| `content` | Text to display in editor panel. |

This control display custom text information.

## Example

```json
...
    "settings": [
        {
            "type": "header",
            "content": "Please upload image of reasonable size"
        },
        ...
    ]
...
```

# text control descriptor

нет дополнительных настроек

Wysiwyg-редактор. Используется CKEditor версии 4.16.0

## Пример:

```json
...
    "settings": [
        {
            "id": "caption",
            "type": "text",
            "label": "Caption",
            "default": "Lorem ipsum"
        },
        ...
    ]
...
```
